# Eiken Bygg: prosjektcaser

Statisk HTML-prototype for totalrenovering på Husøy og ny hytte i Horten.

- `index.html`: oversikt og seks sammenlignbare utkast.
- `husoy.html` og `horten.html`: prosjekttekst og designretninger.
- `?retning=a`, `?retning=b`, `?retning=c`: velg retning.
- `research.html`: referanser, dokumentasjon, designsprint og måleplan.

Ingen installasjon eller bygging er nødvendig. GitHub Pages kan publisere fra main, rotmappen.

Utkast, ikke endring av eiken-bygg.no. Sidene har noindex. Dette er ikke tilgangskontroll.
Kontaktlenker åpner telefon/e-post. Ingen analyseverktøy eller skjema-backend er aktivert.

Prosjekttekst bygger på brukerens to PDF-er og merkevarestrategi. Original-PDF-er og private notater er ikke inkludert. Begge prosjektene bruker tydelig merkede, fiktive KI-illustrasjoner. Henrik-portrettet er hentet fra Eiken Byggs offentlige Om oss-side etter brukerens uttrykkelige bestilling. Ingen bilder av de faktiske byggeprosjektene er publisert. Logoen er hentet fra Eiken Byggs offentlige nettsted.

Bilder, merkevare og innhold tilhører sine respektive rettighetshavere. Ingen generell lisens er gitt.

UX: lett innfading ved skrolling, bildezoom med tastaturvennlig dialog, lesefremdrift og kopiering av delbar lenke. Redusert bevegelse respekteres.

Konverteringsgjennomgang: `optimization-review.md`. Fast kontaktknapp, kontaktanker til Henrik, kontaktpunkt midt i historien og galleri med tastaturbetjening.

Kontaktutkastet har nå skjema med validering. Det oppretter en e-post i besøkendes e-postprogram; det sender ikke direkte og lagrer ikke data. Vedlegg legges til i e-posten. Ingen tilkobling til WordPress/Elementor er etablert.

Herooppdatering 22. september: fullbredde bilde med mobilbeskjæring, kort tittel, tilgjengelig prosjektmeny og kontaktlenke. Intro og sammenligning av designretninger ligger under heroen. Fast kontakt kommer frem etter heroen. Redusert bevegelse respekteres.
